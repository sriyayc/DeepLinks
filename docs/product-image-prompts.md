# Product artwork

Generated with the built-in image generation tool for the four fictional starter products. Images are stored locally in `frontend/static/images/` and require no external image service. `ProductImage.svelte` maps the starter database's existing SVG URLs to these PNG assets; no database migration or reseeding is needed.
